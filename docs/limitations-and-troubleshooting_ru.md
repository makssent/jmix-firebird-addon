# Ограничения и устранение проблем

[English](limitations-and-troubleshooting.md) | [Russian](limitations-and-troubleshooting_ru.md)

## Основные ограничения при использовании Firebird

При использовании Firebird недоступны две функции Jmix Studio:

- **Запуск приложения.** Run Action недоступен для проекта с Firebird из-за проверки схемы базы
  данных перед запуском, поэтому приложение необходимо запускать из командной строки.
- **Автоматическая генерация changelog-файлов Liquibase.** Studio не может сравнивать модель
  сущностей со схемой Firebird и генерировать changeset для изменений модели, поэтому changelog
  необходимо создавать вручную.

Это основные практические ограничения интеграции со Studio. Они не влияют на работу аддона
и приложения с Firebird во время выполнения.

## Другие известные ограничения

Остальные ограничения затрагивают отдельные операции или зависят от версий используемых библиотек
и обычно не препятствуют запуску приложения.

### Поддержка в Liquibase и EclipseLink

Обе библиотеки поддерживают Firebird, но некоторые проверки и механизмы генерации SQL рассчитаны
на старые версии Firebird. Ошибка конкретного типа изменения Liquibase или операции EclipseLink
может быть связана с совместимостью самой библиотеки.

## Границы поддержки

Поддержку Firebird обеспечивает этот аддон сообщества, который сопровождается отдельно от Jmix.
Firebird не входит в число баз данных, официально поддерживаемых командой Jmix, поэтому новые
версии Jmix, Liquibase или EclipseLink могут вызывать проблемы совместимости, требующие обновления
аддона.

Текущая линейка аддона рассчитана на Firebird 4.0+. Jaybird 6 может подключаться к Firebird 3.0,
но поддержка этой версии драйвером JDBC сама по себе не означает совместимость аддона с Firebird 3.0.
Аддон использует возможности, появившиеся в Firebird 4.0, включая типы данных с часовыми поясами
и современный синтаксис последовательностей.

## Устранение проблем

### Запуск приложения с Firebird

Чтобы запустить приложение без Studio Run Action, используйте стандартную задачу Gradle
из командной строки:

```bash
./gradlew bootRun
```

### Изменения модели сущностей и changelog-файлы Liquibase

После изменения модели сущностей создавайте, подключайте и проверяйте соответствующие changeset
Liquibase вручную. Порядок подключения changelog описан в
[руководстве по настройке](configuration_ru.md#настройка-liquibase).

### Jmix не выбирает реализацию для Firebird

**Симптомы:** при запуске появляется сообщение о неподдерживаемом типе базы данных или не выбираются
сервисы, специфичные для СУБД.

**Проверка:** в `application.properties` должно быть указано:

```properties
jmix.data.dbms-type=firebird
```

Также убедитесь, что `jmix-firebird-starter` присутствует в classpath во время выполнения.

### Отсутствует драйвер JDBC для Firebird

**Симптомы:** не удаётся загрузить `org.firebirdsql.jdbc.FBDriver` или найти подходящий драйвер JDBC.

**Проверка:** добавьте Jaybird как runtime-зависимость и перезагрузите проект Gradle:

```groovy
runtimeOnly 'org.firebirdsql.jdbc:jaybird:6.0.5'
```

### Приложение не может открыть базу данных

**Симптомы:** Firebird сообщает, что база данных недоступна или файл не удаётся открыть.

**Проверка:** создайте базу данных до запуска Jmix, проверьте адрес сервера и порт. Путь в JDBC URL
определяется на сервере Firebird. Убедитесь, что указанный пользователь может подключаться
и создавать объекты схемы.

### Liquibase использует неверный тип для UUID или другого свойства Jmix

**Симптомы:** создание схемы завершается ошибкой на `UUID` или changelog модуля Jmix не может
определить значение свойства типа данных.

**Проверка:** подключите changelog аддона перед всеми changelog-файлами модулей Jmix и приложения:

```xml
<include file="/io/github/makssent/jmix/firebird/liquibase/changelog.xml"/>
```

Для столбцов UUID приложения используйте `${uuid.type}`.

### Отсутствует начальный администратор

**Симптомы:** схема создана, но начальный пользователь Jmix не может войти в приложение.

**Проверка:** changeset из шаблона, добавляющие администратора и назначения ролей, часто содержат
список разрешённых СУБД в атрибуте `dbms`. Добавьте в этот список `firebird`, если эти вставки
должны выполняться на Firebird.

### Liquibase отклоняет `createSequence` с `startValue`

**Симптом:** Liquibase сообщает `startValue is not allowed on firebird`, хотя Firebird 4.0
и более новые версии поддерживают начальные значения последовательностей.

Это ограничение связано с версией Liquibase, а не с Jmix или современными версиями Firebird.
Если обновление до версии Liquibase с исправлением невозможно, выделите временный обходной
вариант для Firebird:

```xml
<changeSet id="create-sequence" author="app" dbms="!firebird">
    <createSequence sequenceName="APP_NUMBER" startValue="1000"/>
</changeSet>

<changeSet id="create-sequence-firebird" author="app" dbms="firebird">
    <createSequence sequenceName="APP_NUMBER"/>
    <sql>ALTER SEQUENCE APP_NUMBER RESTART WITH 1000</sql>
</changeSet>
```

Удалите обходной вариант после перехода на версию Liquibase, которая корректно работает с целевой
версией Firebird. Исправление в Liquibase отслеживается в
[liquibase/liquibase#7922](https://github.com/liquibase/liquibase/pull/7922).
